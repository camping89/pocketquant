# Governance

This folder holds the governance rules of the project. Every file here is a rule set that people and agents must follow.

Read every file in this folder before you start work on the project. Add a new rule set as its own file and list it below.

## Rule Sets

| Doc | Covers |
|---|---|
| [Documentation rules](./documentation-rules.md) | When to write a doc line, where content goes instead, and how to keep docs from re-growing. |
| [No look-ahead rules](./no-look-ahead-rules.md) | What data a strategy decision may use, above all closed higher-timeframe bars, and the checks before trusting a multi-timeframe backtest. |
